# Matrix Destiny Bot

Telegram-бот для разборов по системе «Матрица судьбы» (22 аркана).

Бот работает как отдельный проект и не зависит от Арканума.

Telegram:

@matrixRUS_AI_bot

# Возможности

Пользователь:

- бесплатный первый разбор;
- покупка пакетов разборов;
- история разборов;
- баланс разборов;
- AI-интерпретации.

Администратор:

- пользователи;
- статистика;
- последние разборы;
- популярность разделов;
- воронка продаж;
- топ пользователей;
- рассылки;
- акции;
- ручное начисление через /give.
