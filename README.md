# Правила разработки

## Git

Главная ветка:

* main

Разработка:

* только через отдельные ветки

Текущая рабочая ветка:

* matrix-product-skeleton

После каждой заметной доработки:

```bash
git add .
git commit -m "..."
git push
```

## GitHub

Настроен через SSH.

Работает без логина и пароля.

Проверка:

```bash
ssh -T git@github.com
```

Сервер:

```text

├── tarot_bot

```

Matrix Bot:

```text
/opt/bots/matrix_bot
```

Отдельный репозиторий.

Отдельный .env.

Исправлено:

```python
load_dotenv("/opt/bots/matrix_bot/.env")
```
